# SystemUMD

SystemUMD is another x86-64 pure UEFI operating system from the **Universal Micro Devices Open Source Software (UMD OSS)** project. It uses `SystemdBoot` from the `Systemd` project as its initial boot manager.

## Source Repository

You can access the SystemUMD source code at:

<https://github.com/zirconiumtian/SystemUMD>
